# 🌟 Aura

**Aura** is a modern, responsive web application built with a clean
UI/UX focus, designed to deliver a smooth and engaging user experience.
The project showcases a scalable frontend architecture, fast
performance, and seamless deployment.

🔗 **Live Demo:** https://aura-three-omega.vercel.app/\
📦 **Repository:** https://github.com/indrakiran7b/Aura

------------------------------------------------------------------------

## 🚀 Features

-   ✨ Modern and visually appealing UI\
-   📱 Fully responsive design (mobile-first)\
-   ⚡ Fast performance with Vite\
-   🎨 Styled using Tailwind CSS\
-   🔐 Backend integration with Supabase\
-   🧩 Component-based scalable architecture\
-   🌐 Production-ready deployment on Vercel

------------------------------------------------------------------------

## 🛠️ Tech Stack

**Frontend** - React + TypeScript\
- Vite\
- Tailwind CSS

**Backend / Services** - Supabase

**Tooling** - ESLint\
- PostCSS\
- Bun / npm

## ⚙️ Installation & Setup

Clone the repository:

``` bash
git clone https://github.com/indrakiran7b/Aura.git
cd Aura
```

Install dependencies:

``` bash
npm install
```

Run the development server:

``` bash
npm run dev
```

Build for production:

``` bash
npm run build
```

------------------------------------------------------------------------

## 🌍 Deployment

The application is deployed on **Vercel** for fast global delivery.

To deploy your own:

1.  Push the repo to GitHub\
2.  Import into Vercel\
3.  Add environment variables\
4.  Deploy 🚀
